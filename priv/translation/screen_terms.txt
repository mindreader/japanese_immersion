# Terms for Japanese.Translation.Screen, which decides which lines of a
# refused page to withhold (never send) when it is retried.
#
# A line is withheld only when a sexual term (strong or weak) appears near a
# sign of a minor: an age under 18 (13歳, 十三才, １３歳; detected in code, not
# listed here) or one of the [youth] words. Strong terms count up to 8 lines
# from that sign, weak ones up to 3. The withheld passage runs from one to
# the other, plus a line either side.
#
# One term per line. Matching is a plain substring match after Unicode NFKC
# normalisation (so half-width katakana match too), which means a stem covers
# its conjugations: 抱い matches 抱いた and 抱いて. Lines starting with # are
# comments. Edit freely; the file is read each time the screen runs.
